# 빈칸을 읽는 시간 — 홍보 사이트

정적 사이트: HTML/CSS/JavaScript와 data.json만 사용하며 데이터베이스는 없습니다.

## 데이터 관리
콘텐츠 보드에서 행을 편집·추가·삭제하고 JSON으로 내보내거나 불러올 수 있습니다. 브라우저 편집은 localStorage에 저장됩니다. 배포 원본을 바꾸려면 내려받은 JSON을 data.json으로 교체해 저장소에 반영하세요.
